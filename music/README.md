# Music Folder

Folder ini digunakan untuk menyimpan file musik latar.

Repository ini tidak menyediakan file musik bawaan untuk menghindari masalah hak cipta.

Jika ingin menambahkan musik, masukkan file musik sendiri ke folder ini dengan nama:

```text
song.mp3
```

Struktur yang benar:

```text
music/song.mp3
```

Pastikan musik yang digunakan adalah musik buatan sendiri, bebas royalti, atau musik yang memang memiliki izin penggunaan.
