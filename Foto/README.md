# Foto Folder

Folder ini digunakan untuk menyimpan foto yang akan tampil pada halaman `yes.html`.

Tambahkan foto dengan nama berikut:

```text
Foto1.jpeg
Foto2.jpeg
Foto3.jpeg
Foto4.jpeg
Foto5.jpeg
Foto6.jpeg
Foto7.jpeg
Foto8.jpeg
Foto9.jpeg
Foto10.jpeg
Foto11.jpeg
Foto12.jpeg
Foto13.jpeg
Foto14.jpeg
Foto15.jpeg
Foto16.jpeg
```

Pastikan nama file sama persis dengan yang digunakan pada `yes.html`.

Jika ingin memakai nama file lain, ubah bagian `src` pada file `yes.html`.
